Abstração, na prática

O Pilar da Abstração

Definição: o processo de focar nas características essenciais de uma entidade, ignorando detalhes irrelevantes para o contexto do sistema.

Na prática: modelando um Usuario para login, precisamos abstrair email e senha — mas podemos ignorar características físicas ou hobbies, que não importam para a autenticação.
Estrutura

O Que É uma Classe?

  • Uma classe é um molde estrutural, ou um tipo de dado criado pelo programador
  • Define a estrutura fundamental que suas futuras instâncias possuirão
  • Atributos (estado) — as variáveis internas (ex: nome, email)
  • Métodos (comportamento) — as funções que operam sobre esses dados (ex: exibir_perfil())
Instanciação

O Que É um Objeto?

  • Um objeto é a instância ativa de uma classe
  • Quando instanciado, passa a ocupar espaço na memória do sistema durante a execução
  • Carrega dados concretos, baseados nas regras estipuladas pela sua classe de origem
  • Uma definição, infinitas instâncias — cada objeto tem seus próprios valores
Do conceito ao código

Classes e Objetos em Código

A mesma classe Usuario, definida e instanciada nas duas linguagens do laboratório.

Python 
class Usuario:
    def __init__(self, nome, email):
        self.nome = nome
        self.email = email
    def exibir_perfil(self):
        print(f"{self.nome} <{self.email}>")
usuario1 = Usuario("Ana Silva", "ana@email.com")
usuario2 = Usuario("Carlos Moura", "carlos@email.com")
usuario1.exibir_perfil()
usuario2.exibir_perfil()
JavaScript 
class UsuarioJS {
  constructor(nome, email) {
    this.nome = nome;
    this.email = email;
  }
  exibirPerfil() {
    console.log(`${this.nome} <${this.email}>`);
  }
}
const u1 = new UsuarioJS("Ana Silva", "ana@email.com");
u1.exibirPerfil();

Sua Vez: Produto com Desconto

Uma classe Produto guarda nome e preco, e sabe aplicar um desconto que reduz o próprio preço. Escolha Python ou JavaScript — ou pratique as duas.

class Produto: def __init__(self, nome, preco): self. = nome self. = preco def (self, percentual): self.preco = self.preco * (1 - percentual / 100) p = Produto("Teclado", 200) p.(10) print(f"{p.nome}: R$ {p.preco:.2f}")
class Produto { constructor(nome, preco) { this. = nome; this. = preco; } (percentual) { this.preco = this.preco * (1 - percentual / 100); } } const p = new Produto("Teclado", 200); p.(10); console.log(`${p.nome}: R$ ${p.preco.toFixed(2)}`);
