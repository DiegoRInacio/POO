Onde Paramos

Na Aula 02 aprendemos a definir uma Classe e a criar Objetos a partir dela. Hoje fixamos a diferença entre atributos e métodos com um truque rápido, e damos o passo que faz um programa ganhar vida: objetos que chamam métodos de outros objetos.

Um sistema orientado a objetos não é um conjunto de caixas isoladas — é uma rede de objetos colaborando. A inteligência do sistema mora na conexão entre eles, não em cada objeto sozinho.
Truque rápido

Atributos × Métodos: Como Não Confundir

Atributos — a regra do substantivo

Se dá pra descrever com um substantivo ou adjetivo (cor, saldo, tamanho), é atributo. Guarda o Estado — o que o objeto TEM.

carrinho.total_itens

Métodos — a regra do verbo

Se é uma ação executável (verbo no infinitivo), é método. Executa o Comportamento — o que o objeto FAZ.

carrinho.finalizar_compra()

Exemplos de atributos: nome, email_verificado, saldo_conta. Exemplos de métodos: autenticar_senha(), atualizar_saldo().
A mecânica

Passagem de Mensagens

Como as instâncias conversam na memória? Através da passagem de mensagens.

  1. Um objeto (emissor) invoca o método de outro objeto (receptor)
  2. O emissor pode enviar dados adicionais (parâmetros)
  3. O receptor executa sua rotina, altera seu próprio estado e/ou devolve uma resposta

A Interação na Prática

Reaproveitando o cliente_vip da Aula 02 — agora ele interage com um novo objeto, o CarrinhoDeCompras.

Python 
class CarrinhoDeCompras:
    def __init__(self):
        self.itens = []
    def adicionar_item(self, cliente, item):
        self.itens.append(item)
        print(f"{cliente.nome} pegou {item}")
carrinho = CarrinhoDeCompras()
carrinho.adicionar_item(cliente_vip, "Teclado")
JavaScript 
class CarrinhoDeCompras {
