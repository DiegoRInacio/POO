O Paradigma É Universal — a Sintaxe é Tradução

Nas aulas 02 e 03 já escrevemos classes, atributos, métodos e objetos conversando entre si — em Python e em JavaScript. Hoje paramos pra formalizar por que o código de cada linguagem tem essa cara.

O Paradigma — o modelo mental
A forma de pensar e estruturar o problema. É universal: existe independente da linguagem.
A Sintaxe — a gramática
As regras e palavras-chave pra escrever esse modelo numa linguagem específica. É só tradução.
A arquitetura do software é a mesma nas duas colunas de código que você vê desde a Aula 01 — só a gramática muda.
O detalhe que muda tudo

Referência Interna: self × this

Como um objeto acessa os próprios dados de dentro da classe? Ele precisa de um pronome estrutural — e as duas linguagens resolvem isso de formas opostas.

Python — padrão explícito 
def __init__(self, marca):
    self.marca = marca

A linguagem exige que a classe passe a si mesma como o primeiro parâmetro. Você escreve self em toda assinatura de método.

JavaScript — padrão implícito 
constructor(marca) {
  this.marca = marca;
}

A linguagem assume a referência sozinha. this já existe dentro de qualquer método, sem você declarar.

self e this apontam pro mesmo lugar na memória: a instância atual. Só muda quem escreve a palavra.
Sintaxe

Instanciando Objetos na Memória

Python — chamada direta 
meu_carro = Carro("Toyota")
meu_carro.acelerar()

A classe é chamada como se fosse uma função. Nenhuma palavra-chave extra.

JavaScript — a palavra-chave new 
const meuCarro = new Carro("Toyota");
meuCarro.acelerar();

new é obrigatório — sem ele, o construtor não roda do jeito certo.
