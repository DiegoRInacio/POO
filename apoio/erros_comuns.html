Erros Comuns e Armadilhas

Sintoma, causa e correção para falhas recorrentes nos exercícios. Os exemplos são pequenos de propósito: encontre o padrão do erro e aplique-o ao seu código.

Python

1. Esquecer self

O método de instância recebe o próprio objeto como primeiro argumento.

Errado
class Conta:
    def depositar(valor):
        self.saldo += valor
Corrigido
class Conta:
    def depositar(self, valor):
        self.saldo += valor

2. Argumento padrão mutável

A lista padrão é criada uma única vez e acaba compartilhada entre chamadas.

Errado
def adicionar(item, itens=[]):
    itens.append(item)
    return itens
Corrigido
def adicionar(item, itens=None):
    if itens is None:
        itens = []
    itens.append(item)
    return itens

3. Chamar __init__ diretamente

Instancie a classe; o Python chama __new__ e depois __init__.

Errado
produto = Produto.__init__("Teclado", 200)
Corrigido
produto = Produto("Teclado", 200)

4. Comparar objetos sem definir igualdade

Sem __eq__, duas instâncias com os mesmos dados não possuem igualdade de valor personalizada.

Surpresa
Produto("A", 10) == Produto("A", 10)
# False, se __eq__ não foi definido
Corrigido
def __eq__(self, outro):
    if not isinstance(outro, Produto):
        return NotImplemented
    return (self.nome, self.preco) == \
           (outro.nome, outro.preco)

JavaScript

5. Perder o contexto de this

Ao destacar um método do objeto, uma função comum perde o receptor original.

Errado
const exibir = usuario.exibirNome;
exibir(); // this não é usuario
Corrigido
const exibir = usuario.exibirNome.bind(usuario);
exibir();

// Em callbacks:
itens.forEach(item => this.adicionar(item));

6. Esquecer new

Classes JavaScript só podem ser chamadas como construtor.

Errado
const conta = Conta(100);
Corrigido
const conta = new Conta(100);

7. Usar this antes de super()

O construtor da classe-base deve inicializar a instância primeiro.

Errado
constructor(nome) {
  this.nome = nome;
  super();
}
Corrigido
constructor(nome) {
  super();
  this.nome = nome;
}

8. Usar == quando se quer igualdade estrita

== pode converter tipos silenciosamente; === compara tipo e valor.

Conversão implícita
0 == false   // true
"5" == 5    // true
Preferível
0 === false  // false
"5" === 5   // false

10. Capturar erro genérico e escondê-lo

Capture o tipo que você sabe resolver. Se não souber, deixe propagar ou relance.

Esconde qualquer falha
# Python
try:
    processar()
except Exception:
    pass

// JavaScript
try { processar(); } catch (e) {}
Trata com intenção
# Python
except SaldoInsuficienteError as erro:
    informar_usuario(erro)

// JavaScript
if (e instanceof SaldoInsuficienteError) {
  informarUsuario(e);
} else { throw e; }

11. Criar uma “classe Deus”

Se uma classe cadastra usuário, calcula preço, envia e-mail e grava arquivos, ela possui motivos demais para mudar.

Sinais: muitos atributos desconexos, métodos que usam apenas parte do estado, dependências demais e testes que exigem preparar o sistema inteiro. Extraia responsabilidades coesas e faça os objetos colaborarem.

Checklist antes de pedir ajuda

  1. Leia a primeira linha útil do erro e localize arquivo e linha.
  2. Confirme indentação/chaves e a ordem das declarações.
  3. Confira self/this, new e super().
  4. Reduza o caso até o menor exemplo que ainda falha.
  5. Teste caminho feliz e caminho de erro separadamente.
  6. Explique o resultado esperado antes de alterar o código.
