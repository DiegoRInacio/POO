Referência de Sintaxe: Python × JavaScript

Uma cola lado a lado para consultar durante os exercícios. Os exemplos mostram a mesma intenção orientada a objetos nas duas linguagens; use Ctrl + F para localizar um conceito.

Como ler: Python delimita blocos por indentação e recebe self explicitamente. JavaScript usa chaves, this implícito e new para instanciar.

Classe, objeto e construtor

A classe é o molde; o objeto é uma instância concreta. O construtor prepara o estado inicial.

Python
class Pessoa:
    def __init__(self, nome):
        self.nome = nome

    def apresentar(self):
        return f"Olá, eu sou {self.nome}"

pessoa = Pessoa("Ana")
print(pessoa.apresentar())
JavaScript
class Pessoa {
  constructor(nome) {
    this.nome = nome;
  }

  apresentar() {
    return `Olá, eu sou ${this.nome}`;
  }
}

const pessoa = new Pessoa("Ana");
console.log(pessoa.apresentar());

Atributos de instância e métodos

O atributo guarda o estado particular de cada objeto; o método lê ou modifica esse estado.

Python
class Produto:
    def __init__(self, nome, preco):
        self.nome = nome
        self.preco = preco

    def aplicar_desconto(self, percentual):
        self.preco *= 1 - percentual / 100

produto = Produto("Teclado", 200)
produto.aplicar_desconto(10)
JavaScript
class Produto {
  constructor(nome, preco) {
    this.nome = nome;
    this.preco = preco;
  }

  aplicarDesconto(percentual) {
    this.preco *= 1 - percentual / 100;
  }
}

const produto = new Produto("Teclado", 200);
produto.aplicarDesconto(10);

Encapsulamento

O objeto protege seu estado e oferece operações públicas que preservam suas regras.

Python
class Conta:
    def __init__(self, saldo=0):
        self.__saldo = saldo

    @property
    def saldo(self):
        return self.__saldo

    def depositar(self, valor):
        if valor > 0:
            self.__saldo += valor

_nome comunica “uso interno” por convenção; __nome ativa name mangling, mas não torna o dado absolutamente inacessível.

JavaScript
class Conta {
  #saldo;

  constructor(saldo = 0) {
    this.#saldo = saldo;
  }

  get saldo() {
    return this.#saldo;
  }

  depositar(valor) {
    if (valor > 0) this.#saldo += valor;
  }
}

Campos iniciados por # são privados à classe. Uma closure também pode esconder estado fora de uma classe.

Herança e chamada à superclasse

Use herança quando a subclasse realmente “é um” tipo da superclasse. A subclasse pode acrescentar ou sobrescrever comportamento.

Python
class Veiculo:
    def __init__(self, marca):
        self.marca = marca

    def descrever(self):
        return self.marca

class Carro(Veiculo):
    def __init__(self, marca, portas):
        super().__init__(marca)
        self.portas = portas
JavaScript
class Veiculo {
  constructor(marca) {
    this.marca = marca;
  }

  descrever() { return this.marca; }
}

class Carro extends Veiculo {
  constructor(marca, portas) {
    super(marca);
    this.portas = portas;
  }
}
Atenção: no construtor de uma subclasse JavaScript, chame super() antes de acessar this.

Classes e métodos abstratos

Uma classe abstrata define um contrato incompleto para subclasses. Python oferece suporte por abc; JavaScript exige uma convenção.

Python
from abc import ABC, abstractmethod

class GatewayPagamento(ABC):
    @abstractmethod
    def processar(self, valor):
        pass

class PagamentoPix(GatewayPagamento):
    def processar(self, valor):
        return f"PIX: R$ {valor:.2f}"
JavaScript
class GatewayPagamento {
  constructor() {
    if (this.constructor === GatewayPagamento) {
      throw new Error("Classe abstrata");
    }
  }

  processar(valor) {
    throw new Error("Implemente processar()");
  }
}

class PagamentoPix extends GatewayPagamento {
  processar(valor) { return `PIX: R$ ${valor}`; }
}

Interfaces: contrato só de assinaturas

No recorte da disciplina, representamos uma interface em Python com uma ABC sem métodos concretos. Em JavaScript, simulamos a obrigação de sobrescrever.

Python
from abc import ABC, abstractmethod

class Imprimivel(ABC):
    @abstractmethod
    def imprimir(self):
        pass

class Relatorio(Imprimivel):
    def imprimir(self):
        return "Gerando relatório..."
JavaScript
class Imprimivel {
  imprimir() {
    throw new Error("Implemente imprimir()");
  }
}

class Relatorio extends Imprimivel {
  imprimir() {
    return "Gerando relatório...";
  }
}

Exceções customizadas

Dê significado de domínio ao erro criando um tipo específico.

Python
class SaldoInsuficienteError(Exception):
    pass

def sacar(saldo, valor):
    if valor > saldo:
        raise SaldoInsuficienteError(
            "Saldo insuficiente"
        )
    return saldo - valor
JavaScript
class SaldoInsuficienteError extends Error {}

function sacar(saldo, valor) {
  if (valor > saldo) {
    throw new SaldoInsuficienteError(
      "Saldo insuficiente"
    );
  }
  return saldo - valor;
}

try / catch / finally

Proteja somente a operação que pode falhar e capture o tipo de erro que você sabe resolver.

Python
try:
    saldo = sacar(500, 1000)
except SaldoInsuficienteError as erro:
    print(f"Erro: {erro}")
finally:
    print("Operação encerrada")
JavaScript
try {
  const saldo = sacar(500, 1000);
} catch (erro) {
  if (erro instanceof SaldoInsuficienteError) {
    console.log(`Erro: ${erro.message}`);
  } else {
    throw erro;
  }
} finally {
  console.log("Operação encerrada");
}

Polimorfismo: chamada uniforme

Objetos de classes diferentes respondem à mesma mensagem. O código cliente depende do comportamento comum, não do tipo concreto.

Python
class Relatorio:
    def imprimir(self): return "Relatório"

class Fatura:
    def imprimir(self): return "Fatura"

documentos = [Relatorio(), Fatura()]
for documento in documentos:
    print(documento.imprimir())
JavaScript
class Relatorio {
  imprimir() { return "Relatório"; }
}

class Fatura {
  imprimir() { return "Fatura"; }
}

const documentos = [new Relatorio(), new Fatura()];
documentos.forEach(documento =>
  console.log(documento.imprimir())
);
Regra prática: se o laço precisa de uma sequência de if para descobrir o tipo de cada objeto, talvez esteja faltando uma interface comum ou polimorfismo.
