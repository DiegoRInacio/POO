# POO — Programação Orientada a Objetos

Portal da disciplina de **Programação Orientada a Objetos** — Curso de Engenharia de
Software, Universidade de Vassouras. Prof. Me. Diego Ramos Inácio.

🔗 **Site:** https://diegorinacio.github.io/POO/

Todo o conteúdo é apresentado em **Python** e **JavaScript** lado a lado.

## Conteúdo

| Pasta / arquivo | Descrição |
|---|---|
| `index.html` | Portal com as 9 aulas, material de apoio e o simulado |
| `Aula_01.html` … `Aula_09.html` | Slides das aulas (HTML, navegáveis com ← →) |
| `apoio/` | Material de referência (sintaxe Py×JS, UML, exceções, testes) |
| `simulados/` | Simulado P1 interativo (roda o código do aluno no navegador) |
| `exemplos/` | Código-fonte usado em aula |
| `assets/` | CSS, imagens e JavaScript do site |

## Aulas

1. Introdução à POO
